WIRING TO ESP32 DEVKIT V1

MONITOR
VCC        -> VIN (5V)
GND        -> GND
CS         -> GPIO5
RESET      -> GPIO17 (TX2)
DC         -> GPIO16 (RX2) note : change this
SDI (MOSI) -> GPIO14
SCK        -> GPIO18 note : change this
LED        -> GPIO32
SDO (MISO) -> not connected
T_CLK, T_CS, T_DIN, T_DO, T_IRQ -> not connected

INA226
VCC        -> 3V3
GND        -> GND
SDA        -> GPIO21
SCL        -> GPIO22
A0, A1     -> GND

DS18B20
VDD        -> 3V3
GND        -> GND
DQ         -> GPIO4

FPGA (TANG NANO 4K)
GND        -> GND
pin 42     -> GPIO13 (mcu_heartbeat)
pin 10     -> GPIO34 (fpga_heartbeat)
pin 47     -> GPIO35 (fault_code_bus[0])
pin 48     -> GPIO36 / VP (fault_code_bus[1])
pin 1      -> GPIO39 / VN (fault_code_bus[2])
pin 41     -> GPIO2 (boot_success)
pin 40     -> GPIO15 (shutdown_success)

POWER SWITCH (ROCKER)
not connected to any ESP32 or FPGA pin, it switches the power of the whole unit

battery > rocker switch > esp & main system
